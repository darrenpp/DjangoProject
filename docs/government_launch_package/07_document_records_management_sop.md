# 07 Document and Records Management SOP

## Purpose

The OpenKM-style repository is the official evidence and records layer for the platform. It should hold scanned forms, receipts, qualifications, letters, competency documents, source files, and other regulatory evidence in controlled office-scoped folders.

## Repository Scope

| Scope | Use |
|---|---|
| General Registry | Shared non-private reference documents and common records |
| Nursing Council | Nursing Council applications, receipts, qualifications, competencies, letters, and evidence |
| Medical Board | Medical Board applications, receipts, qualifications, letters, and evidence |

## Document Types

Store and classify:

- Scanned application forms.
- Receipts and payment evidence.
- Qualifications and transcripts.
- Identity documents.
- Letters and correspondence.
- Competency assessments.
- Employer verification records.
- Supervisor assessment records.
- Import source workbooks.
- Management reports.
- Registrar decisions and signed outputs.

## Standard Upload Procedure

1. Select the correct office scope.
2. Select or create the correct folder.
3. Upload the document.
4. Add document type.
5. Add title that can be understood by another staff member.
6. Add metadata:
   - Registration number.
   - Practitioner number.
   - Licence number.
   - Receipt number.
   - Source file.
   - Source sheet.
   - Source row.
   - Applicant name.
   - Application reference.
7. Link to application or practitioner record where applicable.
8. Mark official record if it is part of the legal/regulatory file.
9. Set retention years where policy is known.
10. Confirm audit event is recorded.

## Versioning Rule

Do not overwrite official evidence silently.

If a corrected file arrives:

- Add it as a new version.
- Keep the old version.
- Add notes explaining why the version changed.
- Ensure only one version is marked current.

## OCR and Search

Use OCR/extracted text for scanned documents where possible.

Search by:

- Title.
- Original filename.
- Registration number.
- Practitioner number.
- Licence number.
- Receipt number.
- Source sheet.
- Extracted text.

## Duplicate Document Checks

Checksum duplicate detection helps identify repeated uploads.

If duplicate files appear:

- Confirm whether they are legitimate repeated evidence.
- Link each document correctly if repeated intentionally.
- Remove or archive accidental duplicates according to records policy.

## Retention

Retention periods must be confirmed with NDOH legal/records policy.

Temporary recommended placeholders:

- Application and registration evidence: retain for life of registration plus statutory retention period.
- Receipts and finance records: retain according to finance/audit rules.
- Training/institution records: retain according to education and workforce-planning policy.
- Temporary working files: archive or dispose after confirmed promotion into official record.

## Audit Trail

Document audit events should show:

- Created.
- Uploaded.
- Viewed.
- Downloaded.
- Metadata updated.
- Status changed.
- Linked to record.
- OCR processed.
- Access denied.

## Privacy Rule

Never place Nursing Council private documents in Medical Board folders, and never place Medical Board private documents in Nursing Council folders.
