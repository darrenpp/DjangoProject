Bootstrap Data

Loads the supporting reference lists the dashboard depends on, such as setup values and baseline lookup data.

Use it when: a new environment has been prepared or reference data needs to be refreshed before imports.

Configure NC Workflows

Use it when: forms, checklists, public application guidance, or registrar workflow rules need to be refreshed.

Import Provisional

Brings in provisional and graduand source records so they appear in the Nursing Council pipeline and expiry tracking tables.

Use it when: new raw files or updated provisional listings are received from the Council office.

Import Full-Licence

Loads full-licence records for NC2 registration, qualifications, and approved professional profile updates.

Use it when: new full-licence spreadsheets are received or the full-registration sheet has been corrected.

Import Current ATP Data

Loads the latest Authority To Practice workbook, including current-year renewals, workplace data, gender, and payment-linked ATP rows.

Use it when: updated ATP spreadsheets arrive from the Nursing Council office and current-year charts must be refreshed.

Generate Report

Refreshes the reporting snapshot used by management summaries, dashboard totals, and formal reporting outputs.

Use it when: approvals, imports, or data corrections have been completed and updated reporting is needed.

Audit Missing Data

Export Nurses

Use it when: staff need a formatted registry report for review, meetings, or controlled sharing.

Monthly Excel Report

Use it when: preparing monthly updates, meetings, or detailed reconciliations.
