Nursing Council Board Portal

Use this page only for officially appointed Nursing Council board members.

  • Board credentials are for governance officers, committee chairs, and authorised secretariat roles.
  • A Board Request Token is generated after submission for tracking; it does not grant access.
  • Applications are reviewed before account activation; this is a secure two-approver model.
  • All board account activity is recorded in the board audit log.
